# Security policy

## Supported version

Security fixes target the current `main` branch. This starter does not maintain parallel release branches.

## Reporting a vulnerability

Please use GitHub private vulnerability reporting for this repository when available. If that option is unavailable, contact the repository owner privately rather than opening a public issue.

Include the affected route or component, reproduction steps, impact, and any suggested mitigation. Do not include live credentials, session cookies, password-reset tokens, or personal data.

## Scope and production notes

The repository provides secure starter defaults, not a complete production security program. Before an internet-facing deployment, evaluate PostgreSQL, migrations, rate limiting, server-side sessions, secret management, HTTPS enforcement, monitoring, backups, and incident response for your environment.
